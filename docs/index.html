Missing Not at Random Models for Multilevel Analyses of Longitudinal and Intensive Longitudinal Data

Craig K. Enders, Brian T. Keller, and J.P. Laurenceau

Online materials accompanying the paper. The GitHub repository is at github.com/craigenders/mnar-mlm.

Documents

  • MNAR Tutorial — a Blimp and rblimp tutorial that walks through every model in the paper
  • IRT Equivalence — the equivalence between dummy-coded missingness models and item response theory missingness models
  • Blimp Installation Guide
  • Blimp Scripting Quick Start

Repository contents

  • data/ — the four example data sets (growth and intensive longitudinal; dropout and intermittent missingness)
  • rblimp/ — R scripts that fit every model with rblimp, plus the plotting functions used in the tutorial
  • blimp/ — the same models as Blimp scripts
  • docs/ — the documents above
